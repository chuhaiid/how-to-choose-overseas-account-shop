# 海外账号自助商城怎么选

Apple ID、Telegram、Gmail、X、Facebook 这类海外账号,中文网络上多数是在「自助商城」(也叫发卡站)买的:选好商品、付款,系统自动把账号发到页面或邮箱。这类网站长得很像,真正的差别在商品说明和售后规则里。

这份清单只讲**下单前该核对什么、去哪里看**,不给任何一家排名或打分,也不收推广费。

## 先想清楚你要哪种账号

| 你的用途 | 一般够用的选择 | 说明 |
| --- | --- | --- |
| 临时下载一个国区搜不到的 App | 免费共享 Apple ID | 不用花钱,但多人共用、随时失效。可用的共享页见 [免费美区 Apple ID 共享站汇总](https://github.com/chuhaiid/free-us-apple-id-share-sites) |
| 长期自己用,要能改密码 | 独享账号 | 一人一号,拿到后能改密码和绑定邮箱 |
| 工作室、团队批量用 | 批发 | 看有没有数量档位、发货格式方不方便批量导入 |
| 愿意自己动手 | 自己注册 | Apple 账户的注册方法见 Apple 官方说明 [1] |

## 下单前逐项核对

| 核对项 | 去哪里看 | 怎么判断 |
| --- | --- | --- |
| 独享还是共享 | 商品标题、商品详情 | 写明「独享」「一人一号」,并写明能不能改密码。只写「美区账号」、不说独享共享的,下单前先问清楚 |
| 账号状态 | 商品详情 | 地区、新号还是老号、Apple ID 是否已开通 iCloud、是否已购某个 App。这些决定账号能做什么,写得越细越好核对 |
| 发货方式 | 商品页、购物须知 | 自动发货是付款后页面直接显示或发到邮箱;人工发货要等客服。再看发货内容包括哪些:账号、密码,有没有密保、辅助邮箱、2FA 密钥等 |
| 售后范围 | 售后或退款政策页 | 写清楚保什么、不保什么。常见的写法是保「收到时能正常登录」,不保「使用后被平台封禁」。政策页没写的,按不保处理 |
| 质保从哪天算、多久 | 售后政策页、商品详情 | 从发货时算还是首次登录时算;多长时间内反馈有效;反馈要提供什么(订单号、报错截图等) |
| 有没有教程 | 帮助中心、商品详情 | 有没有对应品类的登录教程,教程有没有写到常见报错怎么处理 |
| 订单查询 | 首页「查询订单」入口 | 不注册能不能凭订单号、邮箱或查询密码找回发货内容。发货内容只显示一次的,当场保存 |
| 规则页齐不齐 | 页脚 | 退款、支付、售后、隐私这几页在不在,写得具体不具体 |
| 联系方式 | 联系页 | 在线客服、邮箱、Telegram 等是否公开写在页面上,售后走哪条渠道 |
| 支付方式 | 结算页 | 支持哪些付款方式;付款后没收到账号,先用订单查询找,再联系客服 |

两个最快的筛子:**商品详情写没写清楚独享还是共享、能不能改密码**;**售后政策页存不存在**。这两项打开网站一分钟就能看完。

## 看到这些承诺要多想一步

- 「永不封号」「100% 安全」「终身包换」:账号能不能长期用,取决于 Apple、Telegram、Google 等平台自己的风控,卖家控制不了。以 Apple 为例,Apple 自己写明,账户在密码或账户信息输错次数过多等情况下会被自动锁定 [2]。
- 只有一个下单页、规则页全是客服二维码:出了问题没有书面依据可查。
- 要你提供自己账号的密码或验证码才能「发货」「售后」:Apple 明确提醒,不要把 Apple 账户密码或验证码告诉任何人 [3]。

## 拿到账号以后

1. 当场保存发货内容和订单号。
2. 按发货内容登录一次,确认能用;有问题在质保时间内带订单号反馈。
3. 独享账号按商品说明尽快改密码、换绑定邮箱或密保,账号才真正归你控制。
4. Apple ID:商品说明写「只用于 App Store」的,就只在「媒体与购买项目」里登录,不要在「设置」顶部登录整台手机。原因和做法见 [共享站汇总里的注意事项](https://github.com/chuhaiid/free-us-apple-id-share-sites#用共享-apple-id-之前要知道的事)。
